# UN86 marketing media

Public on purpose: Instagram (through Buffer) needs each image and video at a public address.
Only marketing media and the templates that make it live here. **Never put app code, passwords or customer data in this repository.**

- `posts/` finished posts, named `YYYY-MM-DD-slug.jpg` or `.mp4`
- `kit/` brand files and `make.py`, which turns a week's JSON into images and reels
- `PLAYBOOK.md` how the weekly marketing run works
- `log.json` what has been scheduled, so nothing repeats
